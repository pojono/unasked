# Crowd data: sources and attribution

Runtime data for the "How big is your crowd?" funnel, generated by `scripts/crowd/build.mjs` on 2026-09-23 from the collector outputs in `.cache/crowd/parts/`. Every number was downloaded from the source below (or, for research figures, typed in from the paper and checked). The funnel loads these files same-origin; it makes no third-party requests at runtime.

- StatCounter: worldwide, all 7 continents and 123 countries (the top countries by internet users plus TW). Other countries use their continent, then worldwide.

## Method notes per file

The collectors' full notes (the runtime files carry a short version in `_meta.notes`).

- **base.json**: Most recent non-empty value per economy (mrnev=1); WDI last updated 2026-07-13. pop = mid-year population (people); inet = share of the whole population that used the Internet in the last 3 months (ITU definition, fraction 0-1). popYear and inetYear usually differ: internet users = pop x inet mixes years, state both. countries = WB economies with an ISO 3166-1 alpha-2 code (XK = Kosovo, user-assigned). other = WB economies without one (JG). lowConfidence: economies with no value, a zero value or an internet share older than 2019. notInWB: tz-database (zone.tab) country codes with no World Bank economy: mostly territories the WB counts inside their sovereign (e.g. RE, GP, MQ, GF, YT inside FR) and TW (not a WB economy); the funnel needs a fallback there (no numbers invented here).
- **zones.json**: Clock group = (jan, jul): UTC offsets in minutes east of UTC on 15 Jan and 15 Jul 2026 12:00 UTC. share = fraction of the country's GeoNames-tagged population living on that clock (normalised within the country). Only countries with 2+ zones in zone.tab are listed; every other country is a single clock (share 1). zones = the country's zone.tab ids on that clock (runtime lookup: canonical zone id -> country via zone.tab -> group containing the id; or compute the visitor's Jan/Jul offsets and match jan/jul). zoneShares is aligned with zones: exact-id shares, a secondary detail only. aliases = legacy tz ids (IANA 'backward' links that are not zone.tab entries, e.g. America/Thunder_Bay, Asia/Choibalsan, Brazil/West) whose target is a zone of that group: older browsers may still report them, so use them for country and group lookup too. Places tagged with a neighbouring country's zone on the same clock count toward the group (diagnostics.foreignIds). Places tagged with a clock the country has no zone for are excluded from the denominator (diagnostics.offClock). Brazil uses ADM2 municipalities (BR.txt); everything else cities500 minus feature codes PPLCH, PPLH, PPLQ, PPLW, PPLX. coverage = GeoNames population sum / World Bank population (urban bias: rural areas are under-counted; use shares, never sums). Countries whose zones all share one clock (AR, CY, DE, KZ, MH, MY, PS, UZ) have a single group with share 1, kept for the exact-id detail.
- **deviceuse.json**: phone / tablet / computer = share of internet users who used that device class to go online (people, not page views; a person counts in every class they use, so the three do not sum to 1). Eurostat: % of individuals aged 16-74 who used the internet in the last 3 months (unit PC_IND_IU3, ind_type IND_TOTAL), latest year with a value per country (the device module is not collected every year). phone = I_IUG_MP; tablet = I_IUG_TPC; computer = I_IUG_IPCQ (only desktop/laptop) + I_IUG_IPCTMP (desktop/laptop and also tablet/phone). Eurostat geo EL -> GR, UK -> GB. flags = Eurostat observation flags. IBGE: % of people aged 10+ who used the internet in the last 3 months, by device used (var 10650): computer = microcomputador (desktop or laptop), phone = telefone movel celular, tablet. NTIA: adults 15+, latest wave. The survey asks whether a person uses a smartphone / tablet / laptop / desktop at all (past 6 months), and separately whether they use the internet; values here are device users / internet users (capped at 1), which assumes device users are internet users. range.computer = [max(desktop, laptop), "desktop, laptop or tablet"] / internet users. Survey definitions differ (age range, 3 vs 6 months) and do not match ITU/World Bank internet use; use as conditional shares only. fallback: no survey exists for other countries. PLAN.md: assume 0.95 for phones and flag it; show "no data" for tablets and computers. The EU27 aggregate is given for reference, not as a substitute.
- **settings.json**: Fractions 0-1 (<= 4 significant digits). scope: world | platform (os + browser) | country (values keyed by ISO 3166-1 alpha-2; XK = Kosovo as used by Eurostat). range = [low, high] where the source allows two readings. n = clients/devices behind the figure. Units differ (page loads, clients, app users, survey respondents): never multiply rates with different units without saying so. Settings depend on the platform, so prefer the row matching the visitor's OS/browser over a worldwide row. citeOnly rows are single quoted figures from proprietary or unlicensed pages. contextOnly rows are background figures, not funnel factors. Public copy: the fields valuesAllIndividuals (share of all people rather than internet users) and definitionNotes stay in the build cache (.cache/crowd/parts/settings.json); non-country keys (EA = euro area) sit in `aggregates`.
- **research.json**: Hand-entered from scripts/crowd/research.data.json; every figure checked against the paper PDF on the retrieved date (table/page in each row's cite). Bits are Shannon entropy (a population average, not the visitor's own value). "leftover" = minimum conditional entropy given the single most informative other attribute (Andriamilanto MinNCE x 21.983). "typical" picks the first current study row per split. Rows marked historical describe technology that no longer exists (Flash fonts, NPAPI plugins). Bits from different attributes must not be added, and must never be used to divide a crowd count. Display as "about 2^H groups" / "about X bits left".
- **world.json / countries (StatCounter)**: Share of page views (not people), 12-month aggregate (chart.php bar=1) 2025-08 to 2026-07; the last 45 days (StatCounter revision window) are skipped. Fractions 0–1, 4 significant digits. Top 20 rows + "Other" for most tables (browserVersion lists more). Normalised labels: OS X + macOS = macOS, Chrome OS = ChromeOS, Edge Legacy = Edge; browserVersion summed per family; mobile resolutions in portrait (short side first), tablet/desktop as reported. Tablet "iOS" is iPadOS. Bot pollution is possible on desktop tables (sanity gates run in the build step).
- **countries (Firefox)**: Fractions 0-1 (4 significant digits). mean12w = mean over the weeks each locale was listed within the last 12 report weeks (tags listed in fewer than 6 of them are only in sightings52w). cutoff = 12-week mean of the smallest listed share (the 5th locale when five are listed): unlisted locales are below it. sightings52w meanPct/minPct/maxPct are fractions. ja-JP-macos and ja-JP-mac are merged into ja. Desktop Firefox only; independent of device is an assumption.
- **world.json (languages)**: worldwide.byTag[tag].share = Σ_countries P(tag | country) × internet users ÷ Σ internet users, over the report countries with a World Bank weight; P = mean12w, or (when not in the 12-week top list) min(52-week sighting mean, country cut-off) × weeks listed / 52 (weeks not listed count as zero: conservative). .low uses mean12w only. homeCountries: countries sorted by users of that tag, smallest set covering ≥ 90% (max 40); top5Share = part of the tag's users estimated from 12-week top-5 lists (the rest from sightings; entries marked via: "sightings" are weak evidence — for locales that are nowhere in a top 5, e.g. sq, hy-AM, prefer CLDR official-language countries); s = that country's fraction of the tag's users; countries without a World Bank weight (TW, RE, GP, MQ, GF …) are appended with s = null when the tag is their top locale. firefoxWorldwide12w is Firefox's own worldwide mix (weighted by where Firefox is popular) — reference only, do not use as a worldwide language share.
- **world.json (Wikimedia) and countries `language`**: Fractions 0-1, 4 significant digits. browserWithinOs: worldwide Wikimedia pageviews (not people; Wikipedia readers lean desktop/Firefox), labels normalised to StatCounter-style families (Mobile Safari → Safari, Chrome Mobile/Chrome Mobile iOS → Chrome, Google → Google app, Mac OS X → macOS); rawByOs keeps Wikimedia's families. Unlike StatCounter, the Google iOS app and in-app WebViews are listed separately. wikiLang: reading language (Wikipedia edition), not UI language — people read English Wikipedia because it is larger; automated traffic labelled as users distorts some country-months (median of months used for the API table). Countries Wikimedia withholds for privacy (e.g. IR, RU, CN, TR, VN, SA) only have WikiLingDiv years before mid-2023.

## Caveats

- Each step uses a different source, unit and year: people (World Bank, surveys), page views (StatCounter, Wikimedia), Firefox desktop users (locales), HTTP requests (Radar), app users (Appt).
- StatCounter desktop tables carry bot traffic in many countries; see the `lowConfidence` flags and `fallback` maps.
- UI-language shares come from Firefox desktop only; phone language settings may differ.
