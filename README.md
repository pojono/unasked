# unasked

**What this website knows about you** — a small privacy laboratory that shows, in plain English, what an ordinary web page can learn about your browser *right now*, without asking for a single permission.

Live: **https://pojono.github.io/unasked/**

This repository is the site exactly as it is served: the production build, published automatically. Each deploy is one commit, so you can see what changed and when. The site is developed in a separate repository.
